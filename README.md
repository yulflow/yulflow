Composes and teaches music at Esther Music Academy in Hongdae, Seoul, and studies sound as an M.A. student at MARTE, Dongguk University. Not a developer by training: directs AI agents (Claude Code, Codex CLI) to build the tools that sound, teaching and research actually need, rather than writing most of the code by hand. The stack that runs the day stays private, a set of hubs for skills and session memory, agent orchestration, finance, and foreign-language reading.
